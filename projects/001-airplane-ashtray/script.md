# 001 · 비행기 화장실엔 왜 아직 재떨이가 있을까? — 대본 v1 (확정)

- 형식: 유튜브 쇼츠 9:16, 약 30초 / 콘셉트: A+C 조합 (경험형 도입 + 3지선다 퀴즈)
- 상태: 1단계(텍스트) 대본 확정. 다음: TTS 생성 → 실제 길이 측정 → 2단계 스토리보드

## 내레이션
비행기 화장실 문 옆, 이상한 거 본 적 있죠?
기내는 전부 금연인데… 재떨이가 달려 있어요.
왜 있을까요? 셋 중에 골라 보세요.
1번, 옛날 흔적. 2번, 그냥 장식. 3번, 안전장치.
옛날엔 기내에서 담배를 피웠으니까 1번 같죠? 그런데 지금 규정에도 그대로 있어요.
(0.5초 쉼) 정답은 3번. 금지해도 몰래 피우는 사람이 있거든요.
그 꽁초를 휴지 가득한 쓰레기통에 버리면, 하늘 위에서 불이 날 수 있어요.
그래서 미국 항공 규정은 금연이어도 화장실 문 쪽에 재떨이를 꼭 두게 해요.
몇 번 고르셨어요? 기내 재떨이도… 괜히 그런 게 아니야.
