# 인스타그램 계정 세팅 — 괜히 그런 게 아니야

## 1. 사용자 이름(핸들) — 영문만 가능, 가입 화면에서 사용 가능 여부 확인
| 순위 | 핸들 | 장점 |
|---|---|---|
| 1 (추천) | `gwaenhi.why` | 짧고 외우기 쉬움, '왜?' 채널이라는 게 바로 보임 |
| 2 | `gwaenhi.aniya` | 채널명 끝말 "아니야"와 연결 |
| 3 | `gwaenhi_geureonge_aniya` | 채널명 전체 로마자(길어서 입력이 불편) |

## 2. 이름(검색에 잡히는 칸, 한글 가능, 14일에 2번만 변경 가능)
```
괜히 그런 게 아니야 | 일상 속 왜?
```

## 3. 소개(150자) — SEO: 첫 줄에 계정 핵심 키워드
```
생활 상식 · 잡학 상식 · 과학 상식
일상 속 "왜?"의 진짜 이유를 풀어요
🏠생활 🍜음식 🧍몸 ✈️교통 🧳여행
논문·공식 자료로 확인한 내용만
👇 5분 본편은 유튜브에서
```
- 첫 줄: 검색어 3개(생활 상식·잡학 상식·과학 상식). 프로필을 열었을 때 가장 먼저 보이고, 인스타 검색은 이름·사용자 이름·소개 글을 함께 본다.
- 둘째 줄: 채널 정체성("왜?"), 셋째 줄: 다루는 분야 = 롱테일 키워드, 넷째 줄: 신뢰, 다섯째 줄: 유튜브로 보내는 CTA.
- 이름 칸도 키워드를 맞추려면: `괜히 그런 게 아니야 | 생활 상식`

## 4. 계정 설정
- 계정 유형: 프로페셔널 → **크리에이터**, 카테고리 **교육**(없으면 '디지털 크리에이터'), 프로필에 카테고리 표시
- 프로필 사진: `brand/profile.jpg` (800×800, 원형으로 잘려도 ?·괜히 보임)
- 링크: 유튜브 채널 주소(youtube.com/@괜히그런게아니야)
- 반대로 유튜브 스튜디오 → 맞춤설정 → 링크에 인스타그램 추가

## 5. 올릴 것
- 릴스: 유튜브 쇼츠 원본 파일을 그대로(다른 앱 워터마크가 없는 우리 렌더본이라 괜찮음).
  - 쇼츠 끝 CTA "👉 본편에서"는 인스타에선 링크가 없으니, 릴스용은 "본편은 프로필 링크 👉 유튜브"로 바꾼 버전을 쓰면 좋다.
- 캐러셀(카드뉴스): 인스타에서 저장·공유가 잘 되는 형식. 롱폼 한 편을 6~8장으로 요약.
- 실사처럼 보이는 AI 이미지·영상을 쓴 게시물은 'AI 정보' 라벨을 켠다.
